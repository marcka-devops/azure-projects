# Azure Projects

Azure portfolio for cloud and DevOps engineering roles. This repository is where I publish the infrastructure and automation that show how I design, secure, and operate workloads on Microsoft Azure.

## What this work shows

- Virtual network design, with application and data tiers separated by network security groups
- Identity through Microsoft Entra ID and least-privilege role assignments
- Infrastructure as code in Terraform, with remote state and a reviewable plan before apply
- Separate development and production environments

Each project lives in its own folder so it can be reviewed on its own.
